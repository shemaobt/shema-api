# The **Sound Necklace** answer path has exactly three model steps, and cleanup runs before a human confirms

Between a storyteller's microphone and the artifact, three model steps run and no more.
**Transcription**, which is **Verbatim** and cleans nothing. **Disfluency cleanup**, which runs
after transcription and before translation. And translation into English, which is explicitly
forbidden from cleaning, summarising or completing.

The count is deliberately small, because a model that edits a person's own words is a step no
reader of the artifact can see afterwards. Each one has to be worth defending.

The cleanup is the addition, decided by the owner on 2026-08-08. It is allowed because of
where it sits: it runs before the facilitator confirms the transcript on screen, so a human
still reads and confirms every sentence that reaches an artifact. Nothing a model wrote enters
a report unreviewed. Moving the step after that confirmation would break exactly the property
that admitted it, and is not a refactor to make casually.

This governs one path only. Models are used freely elsewhere on this server, and none of those
uses touch an interview answer. Adding a fourth step here means adding it to this record with
the same argument: what a human sees, and when they see it. Since the 2026-09-01 scope cut the
path has no caller, so the code is dormant rather than gone, and these rules govern whoever
picks it up next.
