# Thin evidence about a legible **Stretch** is no finding, and the passage is **Checked**

Marcia ruled on 2026-09-07 that "cannot judge" is not a kind of finding: it is redundant with
unclear. Weak evidence about a legible frase yields no finding and the round confers, with the
cost named and accepted by her: a false missing costs the team real work, while a thin reading
of a good translation that never closes the passage costs them the passage itself. So checked
means that one whole reading returned no finding, with no evidence flag beside it, and a garbled
frase is still an unclear finding that does not confer.

The only round with no verdict is an analyst reply the server cannot use: broken JSON, an
unknown shape, an API error. Nothing is saved and the voice is not called. A stored
insufficient-evidence finding from before this ruling reads as no finding at all, since under
her rule it was the thin-evidence case.

The rejected alternative was the `evidence_sufficient` flag that gated the conferral. It made the
room ask for a fuller telling of a frase that was perfectly legible, and nothing the team did
could change the answer.
